# TRD-Audio-Suite
TRD Audio Suite is a music player for tracker formats inside ZX Spectrum .trd disk images. Extract and play modules via ZXTune, real-time spectrum visualization, file export. Drag &amp; drop support, create and edit disk images. Compatible with AY/YM, PT3, ASC, STC, TXT and more.
